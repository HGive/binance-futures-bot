# 백테스트 리포트 — spike_drought (롱)

**상태: in-sample 미달, 검증 구간 미사용.**
지금까지 시험한 4개 중 **유일하게 무작위 진입을 크게 이겼다.** 다만 통과 기준에는 못 미친다.

## 가설 — 손매매 방식 그대로

> 년단위로 봤을 때 하락세거나 쭉 횡보인데 그 중 슈팅을 몇 번 한 종목.
> **최근에 슈팅이 없었고** 가격도 상대적으로 낮으면 조금 진입.
> 더 내려가면 추매하거나 초기화해서 계속 슈팅을 기다린다.

이전 시도들이 실패한 이유가 여기서 드러났다. 나는 계속 **슈팅 직후**에 진입하는 걸 시험했는데,
실제 방식은 **슈팅이 한동안 없었을 때** 미리 담아두는 것이다. 정반대였다.

## 1. 슈팅 공백이 결과를 가른다 (핵심 발견)

같은 종목·같은 조건에서 마지막 슈팅 이후 경과일만 바꿔 측정 (19,351 시점 / 124종):

| 슈팅 이후 경과 | 건수 | +33% 먼저 도달 | 1년 내 최대상승(중앙값) |
|---|---|---|---|
| 0~60일 | 8,594 | 40% | +50% |
| 60~120일 | 5,037 | 37% | +41% |
| **120~240일** | 3,161 | **58%** | **+71%** |
| **240일+** | 455 | **64%** | **+132%** |

조용해질수록 좋아진다. 단조롭게 증가하므로 우연으로 보기 어렵다.

## 2. 포트폴리오 백테스트

| 항목 | 값 |
|---|---|
| 데이터 | 215종, 일봉, 2023-08 ~ 2026-08 (1년은 워밍업) |
| in-sample | 2024-09-06 ~ 2026-01-19 (501일) |
| 종목 선정 | 1년 창에 슈팅 3회+, 1년 전 대비 +10% 초과 상승 아님, 일 거래대금 500만+ |
| 진입 | 마지막 슈팅 이후 120일+ 경과, 1년 고저 범위 하위 25% |
| 운용 | 1차 절반 진입 → 가격 -23.3%에서 1회 추매 → 평단 +33% 익절 / 평단 -23.3% 정리 |

| | 전략 | random entry |
|---|---|---|
| 총수익 | **+15.4%** | -47.1% |
| 승률 | **63%** | 43% |
| Profit Factor | 1.23 | 0.60 |
| MDD | -38.5% | -60.2% |
| 트레이드 | 106 | 67 |

**무작위 진입 대비 62%p 차이.** 종목 선정과 진입 타이밍에 실제 정보가 있다.

## 3. 통과 기준 대조

| 항목 | 결과 | 기준 | |
|---|---|---|---|
| 총수익 | +15.4% (약 11%/년) | > 0 | ✅ |
| 트레이드 | 106 | 100+ | ✅ |
| 베이스라인 | -47.1% 대비 초과 | 초과 | ✅ |
| 수익 심볼 | 30/53 (57%) | 절반+ | ✅ |

두 항목 미달이므로 **검증 구간(뒤 30%)은 쓰지 않았다.** (STRATEGY_RULES.md 4.5)

## 4. 확인된 개선점 두 가지

### 펀딩비 — 이 전략은 선물이 아니라 현물이 맞다

평균 보유 42일. 펀딩 0.03%/일이 17개월간 시드의 **6.7%p** 를 가져갔다.

| | 총수익 |
|---|---|
| 선물 (펀딩 있음) | +1.8% |
| 현물 (펀딩 없음) | **+8.5%** |

레버리지는 노출이 같으면 결과가 같다(3배·2배·1배 전부 +1.8% 동일). 즉 이 전략에서
레버리지가 주는 건 수익이 아니라 **강제 손절선과 펀딩비**뿐이다. 사놓고 기다리는 전략에
선물을 쓸 이유가 없다.

### 분산 — 12종목이 최적, 그 이상은 오히려 나빠짐

총 노출을 84%로 고정하고 종목 수만 바꿨을 때:

| 동시 보유 | 트레이드 | 총수익 | MDD | PF |
|---|---|---|---|---|
| 7종목 | 64 | +8.5% | -38.0% | 1.13 |
| **12종목** | **106** | **+15.4%** | -38.5% | **1.23** |
| 20종목 | 156 | +8.0% | -40.1% | 1.14 |
| 30종목 | 195 | +4.4% | -34.7% | 1.11 |

## 5. 남은 문제 — 분산으로 MDD가 안 줄어든다

7종목이든 30종목이든 MDD가 -35~40% 로 거의 그대로다.
**알트는 하락장에서 같이 떨어지기 때문에** 종목 분산이 방어가 되지 않는다.
MDD를 낮추려면 종목이 아니라 **시점**을 피해야 한다. 다음 검증 대상.
