# 백테스트 리포트 — trailing_atr (폐기)

`main` 브랜치의 기본 전략이었고 `main.py` 가 7종목으로 실행하도록 설정돼 있었다.
**한 번도 워크포워드 검증을 거친 적이 없었다.** 이번에 처음 검증했고, 결과는 폐기다.

## 전략

| | |
|---|---|
| 시장/봉 | 바이낸스 선물 15분봉, 롱·숏 |
| 추세 판정 | 가격이 EMA20·EMA120 위 + 두 EMA 3봉 기울기 모두 양수 |
| 진입 | 상승추세인데 RSI < 55 (추세 안 눌림 매수). 숏은 반대 |
| 손절 | 진입가 ∓ ATR × 2.0 |
| 부분 익절 | 가격 ±5% → 50% 청산, 손절을 본전으로, 트레일링 시작 |
| 트레일링 | 최고가 ∓ ATR × 2.5 |
| 레버리지/비중 | 3배 / 티커당 잔고 10%, 동시 7종목 |

## 결과 — 워크포워드 12구간 (2023-08 ~ 2026-08, 선물 15분봉 53종)

| 설정 | 거래 | 승률 | PF | 수익 구간 | 총수익 |
|---|---|---|---|---|---|
| 현재 상수 그대로 | 19,848 | 40.6% | 0.86 | 2/12 | **-100.0%** |
| 파라미터 학습 허용 (27조합) | 10,526 | 36.3% | 0.94 | 2/12 | **-99.8%** |
| 롱만 (숏 제거) | 16,781 | 39.1% | 0.88 | 1/12 | **-100.0%** |

## 파라미터를 넓게 훑어도 살아나지 않는다

손절 ATR배(2/3/4/6) × 트레일 ATR배(2.5/4) × 익절(5/10%) × 레버리지(1/3) × 롱만/롱숏 = **64조합**.

**플러스인 조합 0 / 64.** 최고가 -24.3% (손절 ATR6 / 트레일 4 / 익절 10% / 1배 / 롱만 — 원래 전략과 거의 다른 물건).

## 수수료 탓이 아니다 — 신호가 틀렸다

| 조건 | 포지션 | 포지션 승률 | 총수익 |
|---|---|---|---|
| 현재 그대로 | 21,507 | 23.9% | -100.0% |
| 펀딩비 0 | 21,399 | 23.8% | -100.0% |
| **수수료·슬리피지 0** | 19,789 | **25.2%** | **-93.5%** |
| 수수료 0 + 레버리지 1배 | 19,789 | 25.2% | -42.7% |
| 수수료 0 + 손절 ATR4 / 익절 10% | 5,300 | 26.5% | -99.1% |

**핵심: 포지션 승률 25%.** 4개 중 3개가 익절(+5%) 근처도 못 가고 ATR×2 손절에 걸린다.
15분봉 크립토에서 ATR×2 는 평범한 흔들림 안이다. 목표는 멀고 손절은 그 안에 있다.

## 부가로 확인된 것

- **부분익절 방식은 승률을 부풀린다.** 한 포지션이 PARTIAL 한 줄 + TRAIL 한 줄로 잡혀
  "승률 40.6%" 로 보이지만 포지션 단위로는 25% 다. 리포트를 포지션 단위로 고쳤다.
- 수수료 규모: 포지션 21,507건 × 왕복 0.16% × 3배 = 포지션당 자본의 약 0.05%.
  4년치를 합치면 자본의 수 배다. 신호가 좋았어도 이 회전율은 버티기 어렵다.

## 조치

1. `main.py` 를 그대로 두면 사고가 난다 → 실행 시 경고 후 중단하도록 막았다.
2. `strategies/trailing_atr.py` 는 코드 참고용으로만 남긴다 (주문·트레일링·재시작 복구 로직은 재사용 가치가 있다).
3. **HIBERNATE 가 현재 유일하게 검증을 통과한 전략이다.**
