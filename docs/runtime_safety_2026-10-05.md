# 테스트넷 운영 안전 수정 — 2026-10-05

사용자 요청: 실행 실패, 잔존 주문, 미체결 만료와 위험 관리를 수정하고 계속 개선한다. 구형 코드 동결에 대한 명시적 예외 승인으로 dev1에 적용했다. 실계좌 주문은 실행하지 않았다. v2 코드는 미변경, STATUS만 갱신했다.

## 발견한 원인과 수정

- SWING은 포지션이 없어지면 보유 기록만 삭제했다. 과거 보유 목록까지 포함해 잔여 주문을 취소하고, 포지션 재조회 후 소유 기록을 삭제한다. 취소와 체결이 경합하면 소유를 복구하고 손절을 보존한다.
- 추가 매수에 만료가 없었다. 기본 24시간 GTD, 기존 주문 생성 시간을 기준으로 만료를 이관했다. 만료 시각을 상태에 저장해 재실행/재시작/부분 체결에도 재설정하지 않는다. 만료 11분 전부터는 재주문하지 않는다. 익절·손절은 만료하지 않는다.
- 보호 주문을 가격만 비교했다. reduceOnly, 방향, 종류와 보유 수량을 검사한다. 부분 체결로 수량이 바뀌면 새 손절을 먼저 걸고 기존 손절을 지운다.
- SWING 테스트넷에 칸 예산 20%의 손실 예산(총 자본 약 2%)을 적용했다. 비용 여유 5%를 남기며 현재 및 추가 매수 체결 후 수량을 모두 계산한다. 고점 대비 킬스위치는 최대 -20%로 강화했다. 이 손절 변경의 장기 수익성은 아직 검증하지 않았다.
- 공개 시장정보 실패가 주문 관리를 막았다. 유지보수 모드는 테스트넷 거래소만으로 주문을 점검하고 신규 종목 진입은 하지 않는다. 시간 동기화, 최대 3회 읽기 재시도, 읽기 -1021 재동기화를 추가했다. 불명확한 주문 타임아웃은 재전송하지 않는다.
- 계약 동의 오류 XAU -4411은 차단 상태로 저장했다. 계약 동의 후 수동으로 blocked 항목을 해제해야 한다.
- wrapper의 마지막 echo가 Python 종료 코드를 덮었다. 실패 코드를 저장해 그대로 exit한다. 정상 실행과 유지보수 실행은 같은 OS 파일 잠금을 사용한다. 상태는 임시 파일 후 원자 교체한다.

## 운영 한계

Mac이 꺼지거나 잠자면 로컬 점검은 실행되지 않는다. 이미 거래소에 등록한 손절과 GTD는 거래소가 처리한다. 청산 후 잔여 주문은 다음 점검 전까지 남을 수 있으며, 취소/체결 경합은 재조회와 보호 복구로 처리한다. 완전한 즉시 대응은 실시간 계정 이벤트 감시를 별도로 검증해야 한다.

설치된 wrapper의 이전본은 `~/Library/Application Support/{trendvt,swingdca}/run.sh.before-runtime-fix-20261005`. 예약 정의와 wrapper의 변경본은 `scripts/`에 있다. 변경은 아직 커밋하지 않았다.
