# 워크포워드 검증 결과

## 왜 만들었나

단일 70/30 분할은 앞 구간이 어떤 장이었느냐에 결과가 통째로 좌우된다.
실제로 spike_drought 는 개발구간(BTC +374%)에서 +80%, 검증구간(BTC -37%)에서 -42% 였다.

워크포워드는 이렇게 한다:

```
[학습 365일] → [검증 90일] → 90일 밀기 → [학습 365일] → [검증 90일] → ...
```

각 학습 구간에서만 파라미터를 고르고 바로 다음 90일에 적용한다.
검증 구간들을 이어붙인 것이 최종 성적이다. 상승장·하락장이 자동으로 섞인다.

**데이터**: 바이낸스 현물 일봉 8년 (2018-08 ~ 2026-08), USDT 페어 540종
(상장폐지 페어 포함 — 생존 편향 제거), 검증 구간 24개 / 2,160일.

## 1. 하락장 필터는 실제로 효과가 있다

(4년 데이터, 검증 7구간 기준)

| 필터 | 총수익 | MDD | 승률 | PF |
|---|---|---|---|---|
| 없음 | -25.6% | -48.3% | 49% | 0.68 |
| **BTC 100일선 위에서만 진입** | **+4.5%** | **-21.2%** | 65% | 1.23 |
| BTC 200일선 | -7.1% | -30.9% | 55% | 0.86 |
| 시장 폭 25% 이상 | -17.1% | -37.0% | 49% | 0.70 |
| 시장 폭 40% 이상 | -23.2% | -40.8% | 46% | 0.61 |

필터 하나로 30%p 차이. **단, 필터를 학습 성적으로 '고르게' 하면 안 된다.**
자동 선택 모드는 -27.1% 였다 — 학습 구간이 아직 좋아 보일 때 "필터 없음"을 고르고
바로 다음 90일에 하락장을 맞는다. 필터는 성적으로 고르는 게 아니라 상시 켜두는 것이다.

## 3. 여기서 나온 두 가지 사실

### 물타기가 손실을 키운다 (지금 구조에서는)

- **지는** 포지션은 추매해서 예산 100% 를 다 넣고 -23.4% → 손실 0.47
- **이기는** 포지션은 추매 없이 50% 만 넣고 +32.9% → 이익 0.33

즉 **진 것 1건을 덮으려면 이긴 것 1.4건이 필요**하다. 승률 50% 면 구조적으로 진다.
ROI 만 보면 이기는 쪽이 큰데(+32.9% vs -23.4%) 금액으로는 지는 쪽이 크다.
물타기 자체가 나쁜 게 아니라, **추매 직후에 손절선이 붙어 있으면** 물타기가 손실 증폭기가 된다.

### 손절을 안 하면 승률은 올라가고 자산은 내려간다

마지막 줄이 그것이다. 손절 없이 오를 때까지 기다리면:

- 닫힌 거래의 **승률 94.4%**, Profit Factor 3.67
- 그런데 **총자산 -57.2%**

이긴 것만 닫히고 진 것은 안 닫힌 채 계좌에 남아 있기 때문이다.
8년 동안 닫힌 거래가 18건뿐이고 나머지 자본은 회복을 기다리며 묶여 있었다.
**승률과 자산이 정반대로 움직인다** — 이 구조에서 승률은 성과 지표가 아니다.

## 4. 종합

가장 나은 구조(추매 없음 + BTC 100일선 필터)가 **6년간 +6.8%, 연환산 +1.1%, MDD -57%**.
쓸 수 없다.

다만 같은 구간에 알트 540종 균등 매수는 -52.8%(중앙값 -81.6%) 였다.
**손실을 피하는 쪽에는 분명히 실력이 있다.** 수익을 내는 쪽으로는 아직 부족하다.
