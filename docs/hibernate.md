# HIBERNATE (동면) v1.0 — 워크포워드 통과 버전

**8년 워크포워드 검증을 통과한 첫 전략.** 실전 배포 전 남은 절차는 테스트넷과 소액 실전이다.

**표준 검증 명령** (이 조합이 HIBERNATE v1.0 의 정의다):
```bash
poetry run python backtest/walkforward.py --style adaptive --regime btc_ma100 --quiet
```

## 결정적이었던 발견 3개

### 1. "들어갈 자리" 에는 위아래 경계가 둘 다 있다

목표 ÷ 그 종목의 평소 진폭(= 최근 1년 90일 고저 진폭의 중앙값):

| 비율 | 승률 | 기대값 | 건수 |
|---|---|---|---|
| 0.15 이하 | 35% | **-5.2%** | 3,993 |
| 0.20~0.25 | 48% | +0.3% | 2,073 |
| 0.25~0.30 | 50% | +1.5% | 2,183 |
| 0.30~0.40 | 56% | **+3.5%** | 1,116 |
| **0.60 이상** | **3%** | **-18.2%** | 1,380 |

- **너무 낮으면**: 목표가 그 종목 평소 흔들림보다 작아서 손절에 먼저 털린다.
- **너무 높으면**: 옛날에 크게 슈팅한 기억으로 목표를 잡았는데 지금은 그 거리를 갈 수 없다.

이 필터 하나로 워크포워드가 **-12.3% → +27.1%** 로 뒤집혔다.

### 2. 손절은 고정이 맞다 (진폭 비례로 바꾸면 안 된다)

목표와 손절을 둘 다 진폭 비례로 바꿔봤으나 (a,b) 격자 20조합이 전부 마이너스였다.
조용한 종목일수록 손절이 좁아져 평소 흔들림에 털리기 때문이다.
**목표는 종목별로, 손절은 고정** 이 맞다.

### 3. 물타기를 버려야 한다

추매 직후에 손절선이 있으면 지는 쪽에만 돈을 두 배 넣게 된다.
지면 예산 100%, 이기면 50% 를 투입하므로 **진 것 1건에 이긴 것 1.4건이 필요**해진다.
물타기를 빼자 -32% → +6.8% 로 바뀌었다.

## 남은 한계 — 실전 전에 알고 있어야 할 것

1. **평균 동시 보유가 8칸 중 1.95종목.** 자본의 75% 가 놀고 있다. 기회가 드물다.
2. **2024년 이전 구간은 14구간 중 4구간만 수익.** 총수익이 플러스인 것은 소수의 큰 승리 덕분이다.
3. **탐색과 검증이 완전히 분리되지는 않았다.** 사이징을 고를 때 2024년 이후 결과를 보았다.
   다만 7/10 이라는 구간 승률 자체는 모든 사이징에서 동일했다.
4. **생존 편향은 제거했으나 유동성 편향은 남아 있다.** 거래대금 100만 USDT 하한은
   실제 체결 가능성을 보장하지 않는다. 소액(회당 수백 USDT)에서만 유효한 가정이다.
5. **아직 테스트넷·소액 실전을 거치지 않았다.** STRATEGY_RULES.md 6절의 관문이 남았다.

| 두 번째 자리 추가 (상승추세+고변동+최저가부근) | 청정구간 -26.5% ~ -43.5% | 기각 |
| 보유 시간 상한 (90/120/180/240일) | 청정구간 +31.3% → +6.6~16.5% | 기각 |
| 목표·손절을 둘 다 종목 진폭 비례로 | (a,b) 격자 20조합 전부 마이너스 | 기각 |

**이 표가 중요한 이유**: 채택한 것보다 기각한 것이 훨씬 많다.
같은 데이터를 여러 번 두드렸다는 뜻이므로, 최종 성적은 실제보다 좋게 나와 있을 가능성이 있다.
소액 실전으로 확인해야 하는 이유다.
