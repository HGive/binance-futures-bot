# AI 개입 — 브레이크만, 액셀은 없다

## 왜 이 구조인가

AI 의 장 판단은 **백테스트로 검증할 수 없다.** 검증 안 된 판단이 매매를 *늘리면*
그동안 잰 성적이 전부 무의미해진다. 그래서 구조로 막는다.

| | 가능 | 불가능 |
|---|---|---|
| 신규 진입 | **금지**로 바꾸기 | 코드가 금지한 것을 허용으로 뒤집기 |
| 비중 | **줄이기** (x0.0 ~ x1.0) | 늘리기 (x1.0 초과는 자동으로 1.0 으로 깎임) |
| 보유 포지션 | 건드리지 않음 | — |
| 손절·익절 | 건드리지 않음 | — |

즉 **최악의 경우 AI 개입은 "아무것도 안 사는 것"** 이다. 손실을 키우는 방향으로는 못 간다.

## 기한이 있다

개입에는 반드시 기한(기본 1일, 최대 7일)이 붙는다. 지나면 **자동으로 검증된 기본 동작으로 복귀**한다.

반대로 만들면 안 된다 — "잠깐 꺼두자" 하고 잊으면 영영 안 사게 되고,
그건 백테스트한 전략을 안 돌린 것과 같다.

## 사유가 필수다

`--reason` 없이는 기록이 안 된다. 모든 판단은 `logs/ai_gate_audit.jsonl` 에 남는다.
나중에 **"AI 개입이 실제로 도움이 됐는가"** 를 숫자로 잴 수 있어야 한다.
개입한 날의 성과와 개입 안 했을 때의 성과를 비교하는 게 목적이다.

## 하루 흐름

```bash
# 1) 아침에 숫자를 본다
poetry run python live/briefing.py --save

# 2) 자동 판정을 더 조일 이유가 있으면 기록한다 (없으면 아무것도 안 한다)
poetry run python live/ai_gate.py set --strategy hibernate --block \
    --reason "USDT 디페그 진행 중, 알트 유동성 증발" --days 2

poetry run python live/ai_gate.py set --strategy surfer --size 0.5 \
    --reason "FOMC 하루 전, 변동성 확대 예상" --days 1

# 3) 확인 / 해제
poetry run python live/ai_gate.py show
poetry run python live/ai_gate.py clear --strategy hibernate
```

봇은 매일 점검할 때 이 파일을 읽고, 개입이 걸려 있으면 로그에 사유까지 남긴다.

## 브리핑에 뭐가 나오나

- BTC 가격과 50/100/200일선, 20일·60일 수익률, 30일 변동성
- **BTC 추세성** (1=한 방향, 0=횡보) — SURFER 가 횡보장에서 PF 0.77 로 진다
- **알트 60일 수익 중앙값** — SURFER 의 다른 축
- 알트 폭 (100일선 위 비율)
- 전략별 자동 판정 (HIBERNATE: BTC 100일선 / SURFER: 위 두 조건)

## AI 가 판단할 것 — 숫자에 안 잡히는 것만

자동 판정이 이미 하는 일을 다시 하지 않는다. 다음 같은 것만 본다.

- 스테이블코인 디페그, 대형 거래소 사고·출금 중단
- 규제 발표, 대규모 청산 연쇄
- 특정 종목의 상장폐지 예고·해킹·팀 사고
- 백테스트 기간에 없던 종류의 사건

**"오를 것 같다 / 내릴 것 같다" 는 판단 근거가 아니다.** 그건 이미 숫자가 하고 있다.
