# 스캘핑 — 신호 일괄 탐색 (기각, 그러나 기준선을 얻음)

전략을 하나씩 찍어보는 대신, 후보 신호 14개를 한 번에 재서
**"무작위 진입 대비 승률을 몇 %p 올리는가"** 만 측정했다.

## 먼저: 넘어야 할 선이 얼마인지 계산

무작위 시점에 롱으로 들어가서 TP 가 SL 보다 먼저 오는 비율 (5분봉 490종, 109,670 관측, 수수료 0):

| TP/SL | 이론값 | 실측 | 차이 |
|---|---|---|---|
| +1% / -1% | 50.0% | 49.0% | -1.0%p |
| +1% / -2% | 66.7% | 61.8% | **-4.9%p** |
| +1.5% / -2% | 57.1% | 54.1% | -3.0%p |
| +2% / -2% | 50.0% | 49.5% | -0.5%p |
| +2% / -3% | 60.0% | 53.9% | **-6.1%p** |

**작게 먹고 크게 손절하는 조합일수록 무작위 걸음보다 불리하다.**
대칭(1:1, 2:2)은 거의 공평한데, 비대칭(1:2, 2:3)은 5~6%p 손해다.
이 부족분은 **BTC 상승장(-4.9%p)과 하락장(-4.8%p)에서 똑같다** — 하락장 탓이 아니라 구조다.

여기에 수수료가 얹힌다. TP+1% 대칭 기준:
- 시장가 진입 + 슬리피지 (0.08%) + 청산 (0.02~0.08%) → 왕복 0.10~0.16%
- 이걸 넘으려면 **승률 55% 이상**. 지정가로만 체결시켜 0.04% 로 줄여도 **52% 이상**.

즉 스캘핑 신호는 **승률을 4~7%p 올려야** 한다. 이게 넘어야 할 선이다.

## 후보 신호 14개 측정

TP+1%/SL-1% 대칭, 최대 4시간, 시간 안에 결판난 것만. **159,876 관측 / 477종.**
기준선(무작위 진입) 48.4%.

| 신호 | 최고 구간 | 승률 | 기준 대비 |
|---|---|---|---|
| 24시간 등락 | 중간 분위 | 49.6% | **+1.2%p** |
| 연속 봉 방향 | 하락 연속 | 49.6% | +1.2%p |
| 6시간 등락 | 중하 분위 | 49.5% | +1.1%p |
| 30분 등락 | **상위 분위** | 46.4% | **-2.0%p** |
| 1시간 등락 | 상위 분위 | 46.3% | -2.1%p |
| 2시간 등락 | 상위 분위 | 46.2% | -2.2%p |
| 변동성(ATR) | 상위 분위 | 46.3% | -2.2%p |
| BTC 대비 초과(1h) | 상위 분위 | 46.1% | -2.3%p |

측정한 나머지: 거래량 비율, 하루 안 가격 위치, 이동평균 이격, 몸통/꼬리 비율, UTC 시간대 — 전부 ±1%p 미만.

**최고가 +1.2%p. 필요한 건 +4~7%p.** 기각.

## 별도로 기각된 것: BTC 시차 스캘핑

"BTC 는 올랐는데 아직 안 따라온 알트를 산다" — 사람은 500종을 동시에 못 보지만 프로그램은 본다.
수수료 0 으로 놓고 대조군과 비교:

| 조건 | n | 승률 |
|---|---|---|
| 대조군 (BTC 조건 없음) | 126,460 | 58.7% |
| BTC ≥ +0.5% / 알트 ≤ 0% | 22,698 | 58.2% |
| BTC ≥ +1.0% / 알트 ≤ 0% | 6,942 | 58.5% |
| BTC ≥ +1.5% / 알트 ≤ 0% | 2,695 | 58.7% |
| BTC ≥ +2.0% / 알트 ≤ 0% | 1,219 | 58.2% |

**신호가 아무 차이도 못 만든다.** 알트는 BTC 를 따라가지만, 그 시차는 5분봉이 잡을 만큼 남아 있지 않다.

## 중간에 잡은 착시 (기록용)

처음 측정에서 **저변동성 종목이 +4.3%p** 로 나와 유망해 보였다. 확인해보니:

| 변동성 분위 | 시간초과 비율 | 결판난 것만 승률 |
|---|---|---|
| 최저 1/8 | **50.7%** | 48.7% |
| 2/8 | 5.2% | 49.5% |
| 최고 8/8 | 0.0% | 46.3% |

가장 조용한 종목은 절반이 4시간 안에 ±1% 에 닿지도 못했고,
그 미결판을 '종가가 진입가보다 높으면 승리'로 세면서 승률이 부풀려진 것이었다.
**결판난 것만 보면 48.7% 로 기준 이하다.**
`backtest/scalp_screen.py` 는 이제 미결판 관측을 버린다.

## 남는 것

1. **강하고 일관된 효과는 하나뿐이고 방향이 '피하라' 다.** 최근에 오른 것(30분·1시간·2시간·ATR·BTC 대비 초과 전부 상위 분위)은 -2%p. 8년 일봉에서 본 것과 같은 결론이 5분 단위에서도 나온다.
2. 그 효과는 롱으로 쓸 수 없다 (숏이어야 한다). 롱 전용에서는 **거르는 조건**으로만 쓴다 — HIBERNATE 가 이미 하고 있는 일이다.
3. 스캘핑을 다시 시도한다면 **승률 +4~7%p 를 만드는 신호**가 있어야 한다. 가격·거래량·변동성에서 파생된 신호로는 안 나왔다. 남은 것은 호가창/체결 흐름 같은 봉에 안 담기는 정보이고, 그건 실시간 수집부터 해야 한다.
