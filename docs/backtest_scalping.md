# 검증 리포트 — 1분봉 스캘핑 (급등 추격)

**결론: 안 된다.** 반응속도 문제가 아니라 **가격이 안 따라온다.**

## 가설

"호가나 거래량을 실시간으로 보다가 갑자기 오르는 걸 사람보다 빠르게 따라 들어가서
아주 조금만 먹고 나온다. 사람의 반응속도 패널티가 없으니 가능하지 않나?"

## 검증

1분봉 12종 3개월. 거래량이 20봉 평균 대비 3/5/10배 터지고 +0.2% 이상 오르며
20봉 고점을 돌파한 순간 → 다음 1분봉 시가 진입.

비용은 선물 기준 (현물 수수료 0.1% 로는 스캘핑 자체가 성립하지 않는다):
진입 시장가 0.04% + 슬리피지 0.02% / 익절 지정가 0.02% / 손절 시장가 0.04% + 0.02%

| 거래량 배수 | 건수 | TP+0.3/SL-0.3 | TP+0.5/SL-0.3 | TP+0.8/SL-0.5 | TP+1.2/SL-0.6 |
|---|---|---|---|---|---|
| 3배 이상 | 5,645 | 41% / **-0.156%** | 29% / **-0.174%** | 22% / **-0.321%** | 13% / **-0.475%** |
| 5배 이상 | 3,478 | 40% / -0.163% | 29% / -0.180% | 22% / -0.328% | 13% / -0.482% |
| 10배 이상 | 1,497 | 37% / -0.183% | 26% / -0.201% | 20% / -0.349% | 12% / -0.507% |

전 조합 마이너스. 거래량이 더 크게 터질수록 오히려 나빠진다.

## 왜 안 되는가

### 1. 승률이 손익분기 근처에도 못 간다

| 목표/손절 | 필요 승률 | 실제 승률 |
|---|---|---|
| +0.3% / -0.3% | 65.6% | **41%** |
| +0.5% / -0.3% | 50.0% | **29%** |
| +0.8% / -0.5% | 46.3% | **22%** |

### 2. 비용이 목표를 잡아먹는다

0.3% 를 먹으려는데 왕복 비용이 0.08% — **목표의 27%** 다.
목표를 키우면 비용 비중은 줄지만 도달 확률이 더 빨리 떨어진다.

### 3. 급등 다음은 눌린다 — 모든 시간대에서 동일

이 프로젝트에서 세 번 독립적으로 확인됐다.

| 시간대 | 결과 |
|---|---|
| 일봉 | 슈팅 직후 진입 시 +33% 선도달률 40% (조용한 종목은 58~64%) |
| 15분봉 | 급등봉 다음 24시간 중앙값 -0.40% |
| **1분봉** | **급등 후 30분 내 TP 도달률 41% (동전던지기 이하)** |

**속도를 아무리 높여도 방향이 반대면 소용이 없다.**
프로그램의 이점은 '빨리 들어가는 것'이 아니라 '규칙을 어기지 않는 것'에 있다.

## 이 검증이 다루지 못한 것

호가창(오더북) 단위의 초단위 마이크로구조는 검증하지 못했다.
바이낸스 공개 API 로는 과거 호가 데이터를 받을 수 없기 때문이다.
다만 그 영역은 수수료 리베이트와 회선 지연이 승부를 가르는 곳이라
일반 계정으로 접근할 수 있는 게임이 아니다.
