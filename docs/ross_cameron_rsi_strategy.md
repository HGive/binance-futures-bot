# Ross Cameron RSI + Bollinger Band + MACD 전략

## 전략 철학
> "시장을 예측하려는 순간 트레이더는 이미 실패한 것이다."
> — 오를 확률이 높은 자리만 기다리는 것이 핵심

RSI를 **진입 신호가 아닌 필터**로 사용하고, 캔들 패턴 + 볼린저 밴드로 실제 반전 순간을 포착하는 전략.

---

## 핵심 지표

| 지표 | 설정 | 역할 |
|------|------|------|
| RSI(14) | 30 이하 / 70 이상 | 1차 필터 (과매도/과매수 구간 확인) |
| Bollinger Band(20, 2σ) | 상단/하단 | 가격 확장 폭 검증 + SL 기준 |
| 캔들 패턴 (장악형) | — | 실제 반전 확인 |
| MACD(12,26,9) | 골든/데드 크로스 | 모멘텀 전환 최종 확인 (선택) |

---

## 전략 A: RSI + BB + 캔들 패턴 (쌍바닥/쌍봉)

### Long 진입 조건 (4단계)

```
1단계: RSI < 30 확인
  └─ 예비 신호 → 아직 진입하지 않음

2단계: 음봉 + BB 하단 터치/이탈
  └─ 연속 음봉이 BB 하단을 터치하거나 밴드 밖으로 이탈
  └─ 시장 전반의 공포 확산, 강한 매도 압박 확인

3단계: 첫 번째 장악형 양봉 출현
  └─ 직전 음봉을 **완전히** 집어삼키는 양봉
  └─ 조건: close > prev_open AND open < prev_close (바디 전체 감싸기)
  └─ 하락 힘을 상승 힘이 눌러버린 신호

4단계: 두 번째 바닥 확인 (쌍바닥)
  └─ 가격이 다시 하락하지만, 두 번째 바닥은 **반드시 BB 하단 위**에서 형성
  └─ 첫 번째 바닥: BB 밖이어도 OK
  └─ 두 번째 바닥: BB 안에서 형성 → 과매도 탈출 증거
  └─ 두 번째 양봉 종가에서 진입
```

### Long 청산
- **SL**: 진입 시점의 BB 하단선
- **TP**: R:R = 1:2 (SL 거리 × 2)

---

### Short 진입 조건 (4단계)

```
1단계: RSI > 70 확인
  └─ 과열 상태 인지

2단계: 양봉 + BB 상단 터치/이탈
  └─ 강한 상승으로 양봉이 BB 상단을 찍고 나갈 정도의 과도한 확장

3단계: 첫 번째 장악형 음봉 출현
  └─ 직전 양봉 전체를 덮는 하락 장악형 음봉
  └─ 실질적 매도세 유입 시작

4단계: 두 번째 고점 확인 (쌍봉)
  └─ 두 번째 고점은 **반드시 BB 상단 아래**에서 형성
  └─ 첫 번째보다 높든 낮든 상관없음
  └─ 두 번째 음봉 종가에서 진입
```

### Short 청산
- **SL**: 단기 고점 (BB 상단이 아님 — 거리가 너무 멀 수 있으므로)
- **TP**: R:R = 1:1

---

## 전략 B: RSI 다이버전스 + MACD (속임수 구간 필터)

전략 A의 보조/대체 진입 방식. 세 가지 조건이 **동시에** 충족될 때만 진입.

### 상승 다이버전스 (Long)
```
1. RSI 다이버전스 감지
   └─ 가격: 저점을 낮추며 하락 (lower low)
   └─ RSI: 저점이 높아짐 (higher low)
   └─ 겉으로는 하락이지만, 내부적으로 상승 에너지 축적

2. MACD 골든크로스 확인
   └─ MACD선이 시그널선을 상향 돌파
   └─ 모멘텀이 실제로 바뀌고 있다는 확정 신호

3. 장악형 양봉 출현
   └─ 직전 음봉을 완전히 덮는 양봉
   └─ 매수세가 시장을 장악했음을 최종 확인

→ 장악형 양봉 종가에서 매수 진입
→ SL: 전저점
→ TP: R:R 1:2
```

### 하락 다이버전스 (Short)
```
1. RSI 다이버전스 감지
   └─ 가격: 고점을 높이며 상승 (higher high)
   └─ RSI: 고점이 낮아짐 (lower high)
   └─ 허수 상승 → 폭락 예고

2. MACD 데드크로스 확인
   └─ MACD선이 시그널선을 하향 돌파
   └─ 히스토그램도 양→음 전환 (모멘텀 하락 확정)

3. 장악형 음봉 출현
   └─ 매도세 장악 최종 확인

→ 해당 캔들 종가에서 매도 진입
→ SL: 직전 고점
→ TP: R:R 1:1
```

## 카메론의 핵심 원칙

1. **RSI 50 부근 횡보 종목은 거들떠보지도 말 것** — 변동성 없으면 수익 불가
2. **RSI 70 이상 / 30 이하의 극단적 구간만 노릴 것** — 위험 신호가 아닌 강력한 모멘텀의 시작
3. **RSI는 절대 단독으로 쓰지 않을 것** — 필터(경고등)일 뿐, 캔들 + BB로 실제 반전 확인
4. **쌍바닥/쌍봉의 두 번째 저점/고점은 반드시 BB 내부** — 과매도/과매수 탈출 증거
5. **세 가지 조건 충족 시에만 진입** — 애매한 구간 자연스럽게 필터링
