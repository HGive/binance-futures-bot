# 백테스트 리포트 — shooting_reversion (롱)

**결론: 폐기.** 표본을 늘리자 기대값이 0으로 수렴했다.

## 검증 조건

| 항목 | 값 |
|---|---|
| 데이터 | Binance USDⓈ-M 무기한, 4시간봉 → 일봉 리샘플 |
| 심볼 | 221종 (거래대금 상위 400 중 400일 이상 이력 보유분) |
| 기간 | 2023-08-23 ~ 2026-08-22 (약 3년) |
| in-sample | 2023-08-23 ~ 2025-09-27 (767일) |
| 비용 | 수수료 편도 0.04% + 슬리피지 편도 0.05% + 펀딩 0.03%/일 |
| 베이스라인 | random entry (동일 청산 규칙) |

## 결과

### 1차 — 최초 스펙 (레버리지 2배, 눌린 자리 매수, ROI +100% 익절)

| | 전략 | 베이스라인 |
|---|---|---|
| 총수익 | **-52.5%** | -68.1% |
| MDD | -60.6% | -71.8% |
| PF | 0.37 | 0.42 |
| 트레이드 | 31 | 41 |

베이스라인보다 낫지만 둘 다 크게 잃는다. 청산 구조 자체가 지는 형태.

### 2차 — 진입 조건 재설계 후

진입 신호 이후 실제로 무슨 일이 벌어지는지 직접 측정했다 (in-sample, 관측 120일).

| 진입 조건 | 건수 | 60일 수익 중앙값 | TP+33%/SL-25% 기대값 |
|---|---|---|---|
| V0 눌린 자리 (최초안) | 1,205 | -6.1% | **-8.2%** |
| V1 하락정지 | 715 | -2.8% | -2.4% |
| V2 되돌림 직후 | 1,360 | -7.4% | -7.8% |
| V3 눌림+횡보 | 64 | -25.1% | -15.9% |
| **V4 하락정지 + BTC 50일선 위** | **269** | -5.8% | **+0.2%** |
| V5 되돌림직후 + BTC 상승 | 283 | -5.9% | +0.6% |
| V7 BTC 상승만 | 10,864 | -15.5% | -6.3% |

**심볼 88종만 썼을 때 V4의 기대값은 +15.8% (64건) 였다. 221종으로 늘리자 +0.2% (269건) 가 됐다.**
비용(왕복 0.18% + 펀딩 30일 0.9%)을 빼면 음수다.

같은 조건으로 포트폴리오 백테스트를 돌린 파라미터 그리드(27조합) 결과, **전 조합 손실**(최고 -1.9%).

## 왜 안 되는가

모든 진입 조건 변형에서 **60일 후 수익률 중앙값이 음수**다. 이 종목들은 슈팅을 반복하지만
슈팅 사이의 바닥이 계속 내려간다. 바닥에서 사서 기다리는 쪽에 서면 시간이 적이 된다.
슈팅이 오긴 오는데(120일 내 최대상승 중앙값 +47%), 그 전에 손절선(-38%)이 먼저 닿는 경우가 절반이다.
